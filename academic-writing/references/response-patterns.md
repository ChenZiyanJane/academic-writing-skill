## 8. Source-integration check

For each borrowed passage, identify:
- source function;
- direct quote / paraphrase / summary;
- attribution present?;
- wording too close?;
- citation present?;
- writer explanation after source?;
- revision needed.

## 9. Academic rewrite

When the user requests rewriting, produce a revised version that:
- preserves factual meaning;
- keeps uncertainty and qualification;
- does not invent evidence;
- removes redundancy;
- strengthens logical links;
- uses precise, readable academic prose;
- preserves existing citations unless they are clearly malformed and the user asks to fix them.

If the source text contains a substantive gap, note the gap separately instead of silently filling it.
